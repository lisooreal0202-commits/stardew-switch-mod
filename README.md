# 星露谷物语（Switch）Mod — v1.0

给 Switch 版星露谷加一批实用功能：自动化、拖拉机、地图标记、背包扩容，
外加一个 Tesla 插件（物品、加速、体力、金钱、时间）。

## 版本历史

| 版本 | 日期 | 说明 |
|---|---|---|
| **v1.0** | 2026-11-06 | 首个正式版：之前内部版本的功能全部合并在这一版 |

包含整箱搬运、背包 48 格、地图标记、动画加速、拖拉机、自动化、一击必杀，
以及插件里的全部功能。本版新加屏幕左上角三行信息（明日天气 / 今日运气 / 工具升级），
并把走路加速、自动钓鱼放进金手指——开机就生效，不用先打开插件。

版本号从 v1.0 起算，开发过程中的内部版本不对外发布，所以编号不连续。

## 第一步：先备份存档

**【先备份！先备份！先备份！】**

装之前先用 **JKSV** 备份（本包不含，自己装）：JKSV → 选《星露谷物语》→ 备份。
出问题就 JKSV → 选那个备份 → 恢复。

这个 Mod 直接改游戏代码。主要功能都上机测过，但没法保证所有场景都测到，**不备份就别装**。

## 只支持 Switch 版 1.6.15.13

主界面选中游戏按 `+` →「软件信息」核对。版本不对时 Mod 会自己关掉：不崩、不坏档，但功能全无。

## 安装

1. 解压，把 `atmosphere` 和 `switch` 两个文件夹整个拖到 SD 卡**根目录**，提示覆盖选「是」
2. 装完**最好完全关机**再开机（别只休眠）

```
SD:/atmosphere/contents/0100E65002BB8000/exefs/subsdk8
SD:/atmosphere/contents/0100E65002BB8000/exefs/main.npdm
SD:/atmosphere/contents/0100E65002BB8000/cheats/E7F845093E8CBC68.txt
SD:/switch/.overlays/sdv_items.ovl
```

`subsdk8` 和 `main.npdm` 必须两个都在，缺一个不工作；`sdv_items.ovl` 是插件，
可以不装，但别放进 `atmosphere/`；`cheats` 里那个 txt 是金手指，见下面。

装好验证：按 `+` →「选项」，能看到**锤子图标**的页签 = 加载成功。

## 功能一览

| 功能 | 怎么用 |
|---|---|
| 左上角三行信息 | 明日天气（含节日名）、今日运气、工具升级，装上就有 |
| 整箱搬运 | 用**镐**敲非空箱子 → 整箱进背包（背包要有空位） |
| 背包 48 格 | 皮埃尔杂货店买第三档，20,000 金（原版只有两档） |
| 动画加速 2 倍 | Mod 页开关。只加快动作和对话，**不改游戏时间** |
| 地图增强 | 世界地图上显示 NPC 头像、委托 `!`、生日标记 |
| 走路加速 / 自动钓鱼 | **金手指**，装完进游戏就生效，不用开菜单 → 见下 |
| 拖拉机 | 空手按 `Y` 召唤，骑上去自动干活 |
| 自动化 | 箱子贴着机器放，机器自己取料、收成品 |
| 一击必杀 | 默认关，在插件「增强」页开 |

**Mod 页**：按 `+` →「选项」→ 锤子图标的页签。开关状态跟着存档走，重启后保留。

<details>
<summary><b>走路加速 / 自动钓鱼：为什么在「金手指」里</b></summary>

这两项是**改游戏代码的固定值**（速度改两条指令，钓鱼改十六条），不依赖任何运行时判断，
所以交给 Atmosphère 自带的金手指引擎——它在**游戏启动那一刻**就把值写进去，
不用先打开插件菜单。

文件：`SD:/atmosphere/contents/0100E65002BB8000/cheats/E7F845093E8CBC68.txt`

**文件里只有两段，两段都生效**：

| 段名 | 效果 |
|---|---|
| 走路加速 2x | 走路和跑步都是原版 2 倍 |
| 自动钓鱼 | 抛竿、收竿还是要自己按；小游戏照常弹出，但不用管——浮标判定恒真，进度条自己涨满 |

为什么不能把 4 档速度都写进同一个文件：Atmosphère **默认让文件里所有段全部生效**，
不是「只开一段」。四档写在一起会互相覆盖，最后一段赢；再加一个「关闭」段的话，
等于开机就把前面全撤销，什么都开不了。所以这个文件只留一档。

**想换速度**：同目录下 `可选档位/` 里有 `走路加速-3x.txt`、`-4x.txt`、`-8x.txt`，
把想要的那份内容整个覆盖到 `E7F845093E8CBC68.txt` 就行。也可以直接改那两行：

| 档位 | 第一行 | 第二行 |
|---|---|---|
| 2x（默认） | `04000000 013DA0BC 52856048` | `04000000 013DA0C0 72A7C0E8` |
| 3x | `04000000 013DA0BC 52981068` | `04000000 013DA0C0 72A7C948` |
| 4x | `04000000 013DA0BC 52856048` | `04000000 013DA0C0 72A7D0E8` |
| 8x | `04000000 013DA0BC 52856048` | `04000000 013DA0C0 72A7E0E8` |

`可选档位/` 里的文件不会被自动加载——引擎只读 `<Build ID>.txt`，所以放着不影响，
换了才生效。

**想全关**：把整个 txt 删掉（或改名），速度回原版、钓鱼回小游戏。

**装完没变化**：先核对文件名是不是 `E7F845093E8CBC68.txt`（= Build ID），
再确认 `atmosphere/config/system_settings.ini` 里没把 `dmnt_cheats_enabled_by_default`
设成 `0`——那一项关掉时，任何金手指都不会加载。

**游戏更新后**：文件名就是 Build ID 的前 16 位，游戏一升级文件名就对不上，
金手指会**静默失效**（没有任何提示）。到时候把文件名改成新的 Build ID 就行。

</details>

<details>
<summary><b>拖拉机：怎么召唤、8 个子开关各管什么</b></summary>

**召唤**：把工具收进背包、手上什么都不拿 → 按「使用工具」键（默认 `Y`）。
拿着工具按没反应，这是防误触。第一次要在农场召唤，之后镇上、矿洞也能用。

| 子开关 | 手上拿 | 效果 |
|---|---|---|
| 锄地 / 浇水 | 锄头 / 水壶 | 一次处理一片，范围按工具等级算（开拖拉机时强制提高） |
| 斧头 / 镐子 | 斧头 / 镐子 | 3×3 每格各砍/敲一次。树只算一次，大石头会同时挨好几下 |
| 割草 | 镰刀 | 3×3 割杂草（掉纤维）和草地（掉干草） |
| 打怪 | 剑 / 棍 / 匕首 | 每移动一格打一次周围 3×3。**镰刀不参与** |
| 挤奶剪毛 | 挤奶桶 / 剪刀 | 自动找身边的动物 |
| 播种施肥 | 种子 / 肥料 | 3×3 每格放一个，**一次消耗 9 个** |

关掉一个子开关 = 那类工具骑着时**完全不动作**（不是效果减弱）；下马手动用不受影响。
关掉「启用拖拉机」时子开关会隐藏，但状态记着，重新打开会恢复。

**外观**：装上就是拖拉机的样子，不影响你养的马，也不影响功能。
想变回原版马，删掉这一个文件即可：

    SD:/atmosphere/contents/0100E65002BB8000/romfs/Content/Animals/horse.xnb

那张贴图上半张是原版马的图、下半张是拖拉机，所以它同时受两边的版权约束：
拖拉机部分来自 Pathoschild 的
[Tractor Mod](https://github.com/Pathoschild/StardewMods)（MIT License），
马的部分是游戏本体的。它只随这个包分发，不在仓库里。

</details>

<details>
<summary><b>自动化：怎么摆、什么会断开</b></summary>

三步：箱子**贴着**机器放 → 往箱子放原料 → Mod 页打开「启用自动化」。

- 只能**上下左右**相邻，斜角不算
- **空格、草地、耕地、树、石头、水面**都会断开链条
- 冰箱、朱尼莫箱、迷你出货箱能穿过去，但**不当仓库**，成品不会进它们
- 只处理当前已加载的地图
- 一个组最多 **64 个箱子、160 台机器**，超了可能崩

| 摆法 | 例子 | 说明 |
|---|---|---|
| 直接贴 | 箱子 → 熔炉 | 紧挨着 |
| 一串共用 | 箱子 → 桶 → 桶 → 桶 | 三个桶都从这个箱子取料，成品也回这里 |
| 箱子串联 | 箱子 → 箱子 → 熔炉 | 算一个组，成品往第一个装得下的放 |
| 大制作物当导线 | 箱子 → 稻草人 → 稻草人 → 熔炉 | 稻草人连成一排，可以跨远距离 |
| 地板当导线 | 箱子 → 地板 → 地板 → 熔炉 | 最省事 |
| 拐弯 | 箱子 → 地板 → 地板 → 熔炉 | 上下左右都能走，斜角不行 |

**✗ 箱子 → 空格 → 熔炉**：中间空一格就断，两边都不工作。

箱子满了成品留在机器里，不会丢，腾出空间自己继续放。
目前能自动的：熔炉、酒桶、煤炭窑、木桶陈酿、树液采集器、鱼塘。规则全按原版。

</details>

## 插件（可选）

`switch/.overlays/sdv_items.ovl`，游戏里按 `L + ↓ + Select` 呼出（以你的 Tesla 设置为准）。

| 页面 | 里面有什么 |
|---|---|
| 物品 | 1856 条物品分 7 类，选品质；`ZL` 切数量、`Y` 切品质 |
| 搜索 | 拼音首字母、英文、编号都能搜 |
| 增强 | 体力不减、一击必杀、掉落倍率、素材锁 999、自动浇水、无限水壶、收集品/配方全解锁（走路速度和自动钓鱼已移到金手指） |
| 金钱 | 预设 3 万 / 6 万 / 50 万 / 9.9 亿，也能自己填 |
| 日期时间 | 改日期时分，按「写入游戏」生效，不触发日界 |
| 好感 | 一键全 NPC 2500，也能还原 |

「增强」里的开关**每次开机后要打开一次插件菜单**才重新生效（补丁在内存里）。
插件自己会检查游戏版本，不对就提示「游戏版本不匹配，未写入」，一个字节都不写。

## 已知情况（不是故障）

| 现象 | 说明 |
|---|---|
| 骑拖拉机不扣体力 | 3×3 一次挥动，体力结算后还原 |
| 拖拉机自动打怪伤害很低 | 写死 1~3 点，想秒杀在插件里开「一击必杀」 |
| 挤奶剪毛时「没有奶」红字刷屏 | 原版提示没屏蔽 |
| 镐在耕地上会铲掉耕地和作物 | 原版行为 |

## 不做什么

钓鱼、矿车、抛竿收杆、弹弓、车库建筑、联机。
