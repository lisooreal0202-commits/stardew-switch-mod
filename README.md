# 星露谷物语（Switch）Mod — v1.4.1

给 Switch 版星露谷加自动化、拖拉机、地图标记、背包扩容，作物/机器/礼物提示，
外加一个 Tesla 插件（物品、体力、金钱、日期时间、好感）和一个金手指（走路加速、自动钓鱼）。

## 装之前

**先备份存档。** 用 JKSV（本包不含）：选《星露谷物语》→ 备份。如果出问题可以恢复。

**只支持 Switch 版 1.6.15.13。** 主界面选中游戏按 `+` →「软件信息」核对。
版本不对时 mod 会自己关掉：不崩、不坏档，但功能全无。

## 安装

解压，把 `atmosphere` 和 `switch` 拖到 SD 卡根目录，覆盖选「是」，然后**完全关机**再开机。

```
SD:/atmosphere/contents/0100E65002BB8000/exefs/subsdk8
SD:/atmosphere/contents/0100E65002BB8000/exefs/main.npdm
SD:/atmosphere/contents/0100E65002BB8000/cheats/E7F845093E8CBC68.txt
SD:/switch/.overlays/sdv_items.ovl
```

`subsdk8` 和 `main.npdm` 缺一个就不工作。`sdv_items.ovl` 是插件，可以不装。

验证：按 `+` →「选项」，能看到**锤子图标**的页签 = 加载成功。

## 功能

| 功能 | 怎么用 |
|---|---|
| 左上角四行信息 | 明日天气（含节日名）、今日运气、今日生日（含「最爱 X·Y」）、工具升级 |
| 礼物口味提示 | 日历停在生日那天，或社交页停在村民身上 → 弹出他最喜欢的礼物（带图标） |
| 作物提示 | 走到作物前，格子上方写「作物名 / 还剩几天·浇没浇水」 |
| 机器提示 | 走到熔炉、小桶、木桶、蟹笼前，写「产物 / 还剩多久」；木桶标出下一档品质星 |
| 整箱搬运 | 用**镐**敲非空箱子 → 整箱进背包（要有空位） |
| 背包 48 格 | 皮埃尔杂货店买第三档，20,000 金 |
| 动画加速 2 倍 | Mod 页开关。只加快动作和对话，**不改游戏时间** |
| 地图增强 | 世界地图上显示 NPC 头像、委托 `!`、生日标记 |
| 走路加速 / 自动钓鱼 | **金手指**，开机就生效，不用开菜单 |
| 拖拉机 | 空手按 `Y` 召唤，骑上去自动干活 |
| 自动化 | 箱子贴着机器放，机器自己取料、收成品 |
| 一击必杀 | 默认关，在插件「增强」页开 |

Mod 页：按 `+` →「选项」→ 锤子页签。开关状态跟着存档走。

<details>
<summary><b>金手指：为什么在文件里、怎么换档</b></summary>

这两项改的是代码里的固定值，不依赖运行时判断，所以交给 Atmosphère 的金手指引擎，
游戏启动那一刻就写进去。

文件：`SD:/atmosphere/contents/0100E65002BB8000/cheats/E7F845093E8CBC68.txt`

Atmosphère **默认让文件里所有段全部生效**，不是只开第一段。所以四档速度写在一起会
互相覆盖，**最后一段赢**——2x 放在最后，开机就是 2x。

- **换档**：把想要的那段挪到 `[自动钓鱼]` 前面，或用金手指工具只留一段。
- **全关**：删掉整个 txt。
- **装完没变化**：先看文件名是不是 `E7F845093E8CBC68.txt`（= Build ID），
  再看 `atmosphere/config/system_settings.ini` 里 `dmnt_cheats_enabled_by_default` 没被设成 `0`。
- **游戏更新后**：文件名就是 Build ID，升级后对不上会**静默失效**，改名即可。

</details>

<details>
<summary><b>拖拉机：召唤、8 个子开关</b></summary>

收好工具、空手 → 按「使用工具」键（默认 `Y`）。拿着工具按没反应，防误触。

| 子开关 | 手上拿 | 效果 |
|---|---|---|
| 锄地 / 浇水 | 锄头 / 水壶 | 一次一片，范围按工具等级算 |
| 斧头 / 镐子 | 斧头 / 镐子 | 3×3 各砍/敲一次 |
| 割草 | 镰刀 | 3×3 割杂草和草地 |
| 打怪 | 剑 / 棍 / 匕首 | 每移动一格打周围 3×3，镰刀不参与 |
| 挤奶剪毛 | 挤奶桶 / 剪刀 | 自动找身边的动物 |
| 播种施肥 | 种子 / 肥料 | 3×3 每格一个，**一次消耗 9 个** |

关掉一个子开关 = 那类工具骑着时完全不动作；下马手动用不受影响。

**外观**：删掉下面这个文件就变回原版马（不影响功能）。

    SD:/atmosphere/contents/0100E65002BB8000/romfs/Content/Animals/horse.xnb

那张贴图上半是原版马、下半是拖拉机，同时受两边版权约束：拖拉机部分来自 Pathoschild 的
[Tractor Mod](https://github.com/Pathoschild/StardewMods)（MIT），马是游戏本体的。

</details>

<details>
<summary><b>自动化：怎么摆、什么会断开</b></summary>

箱子**贴着**机器放 → 往箱子放原料 → Mod 页打开「启用自动化」。

- 只能上下左右相邻，斜角不算
- 空格、草地、耕地、树、石头、水面都会断开
- 冰箱、朱尼莫箱、迷你出货箱能穿过，但不当仓库
- 只处理当前已加载的地图
- 一组最多 64 个箱子、160 台机器

地板、稻草人这类大件可以当导线跨距离。箱子满了成品留在机器里，不会丢。

能自动的：熔炉、酒桶、煤炭窑、木桶陈酿、树液采集器、鱼塘。

</details>

|---|---|

| 地图增强 | 地图上的头像、委托、生日标记 |

| 作物/机器提示 | 关掉格子上方的作物气泡和机器气泡 |

## 插件（可选）

`switch/.overlays/sdv_items.ovl`，游戏里按 `L + ↓ + Select` 呼出（以你的 Tesla 设置为准）。

| 页面 | 里面有什么 |
|---|---|
| 物品 | 1856 条物品分 7 类，选品质；`ZL` 切数量、`Y` 切品质 |
| 搜索 | 拼音首字母、英文、编号都能搜 |
| 增强 | 体力不减、一击必杀、掉落倍率、素材锁 999、自动浇水、无限水壶、收集品/配方全解锁 |
| 金钱 | 预设 3 万 / 6 万 / 50 万 / 9.9 亿，也能自己填 |
| 日期时间 | 改日期、改时间。时间走游戏自己的十分钟更新；日期写入立即生效，跨季在睡觉时完成 |
| 好感 | 一键全 NPC 2500，也能还原 |

「增强」里的开关每次开机后要打开一次插件菜单才重新生效（补丁在内存里）。
插件会检查游戏版本，不对就提示「游戏版本不匹配，未写入」，一个字节都不写。

## 已知情况（不是故障）

| 现象 | 说明 |
|---|---|
| 骑拖拉机不扣体力 | 3×3 一次挥动，体力结算后还原 |
| 拖拉机打怪伤害很低 | 写死 1~3 点，要秒杀在插件里开「一击必杀」 |
| 挤奶剪毛时「没有奶」红字刷屏 | 原版提示没屏蔽 |
| 镐在耕地上会铲掉耕地和作物 | 原版行为 |
| 果酒 / 果汁的图标都是同一个瓶子 | 游戏按原料给瓶子上色，这里不叠色；名字会写「上古水果果酒」 |
| 木桶的星是**下一档**，不是当前档 | 刚放进去没有星是正常的：普通品质还没到银星 |

不做的：钓鱼、矿车、抛竿收杆、弹弓、车库建筑、联机。
